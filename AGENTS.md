# Repository agent instructions


## Personal knowledge wiki

When producing or materially updating durable research, analysis, design decisions, or operational documentation, maintain the personal Obsidian wiki when it is available. Read `C:/Develop/knowledge-wiki/AGENTS.md` and `C:/Develop/knowledge-wiki/sources.md` for the current rules and source list. Record evidence, dates, assumptions, limitations, and the source path and revision or uncommitted state. Preserve source documents and existing wiki notes; never copy credentials, sessions, raw private messages, or other sensitive data. If the wiki or source instructions are unavailable, report that and do not block unrelated repository work. Do not run live jobs merely to update the wiki.
